# Computer Fundamentals & Programming | Practical Course Repository

This repository contains the **source code, examples, exercises, and practical implementations** developed throughout the practical part of the **Computer Fundamentals & Programming** course.

The goal of this repository is to turn theoretical concepts into practical programming skills through **problem solving, algorithm implementation, coding, testing, and debugging**.

---

## 🎯 About the Course

The **Computer Fundamentals & Programming** course is designed to teach fundamental computer and programming concepts **from absolute zero**, with no prior programming knowledge required.

The course combines theoretical concepts with examples, problem solving, and practical implementation.

### Course Information

- ⏱️ **Duration:** Approximately 40 hours
- 📚 **Prerequisites:** None
- 🎯 **Main Target:** Master's and PhD entrance exam candidates in Computer Engineering
- 💻 **Additional Audience:** Computer Engineering and Computer Science students, as well as anyone interested in learning programming fundamentals

---

## 💻 About This Repository

This repository is dedicated to the **practical part of the course**.

It contains source code and practical implementations corresponding to the topics covered throughout the course. The examples are organized progressively, starting from basic programming concepts and moving toward more advanced topics.

The repository is intended to be used alongside the course lectures.

---

- Signed number representation

- Two's complement

### 3. Algorithms & Flowcharts
- Problem analysis
- Algorithm design
- Sequential algorithms
- Decision-making
- Repetition and loops
- Flowchart representation
- Implementation of basic algorithms

### 4. Input & Output Formatting
- `printf`
- `scanf`
- Formatted output
- Formatted input
- Precision and numerical formatting
- Integer, floating-point, character, and string input/output

### 5. Control Structures
- `if`
- `if / else`
- `switch`
- `while`

- Logical operators
- Type conversion

### 6. Functions & Memory
- Function definition and invocation
- Function prototypes
- Mathematical functions

### 7. Debugging
- Common programming errors

### 8. Arrays, Searching & Sorting
